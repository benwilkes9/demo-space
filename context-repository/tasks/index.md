# Tasks

Story pages for the Lighthouse board. Not listed here individually — the file
tree normally does that job, except this folder is hidden from the Context
tree because the Board tab renders these same pages as cards.

A story page's `status` is the card's column, and it is authoritative: the
board holds no state of its own. The five columns are `backlog`, `ready`,
`in-progress`, `awaiting-human-review` and `done`. A move rewrites that one
line and commits the page.

Ids use the `LH-` prefix and are never recycled.
