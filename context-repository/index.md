# Context Repository

The corpus for **Lighthouse** — a status page and incident-communication tool
for small ops teams. This is a demo corpus: small on purpose, real enough that
the Context view and the Board have something worth looking at.

## Where to start

| You want to                  | Read                                                   |
| ----------------------------- | ------------------------------------------------------- |
| know why Lighthouse exists    | [Product vision](product/product-vision.md)            |
| look a term up                | [Glossary](product/glossary.md)                        |
| know how it is built          | [Architecture](architecture/architecture.md)            |
| understand a decision         | [ADR-0001](architecture/adrs/0001-postgres-as-the-incident-log.md) |
| know what is being worked on  | the **Board** tab — see [Tasks](tasks/index.md)         |

## Navigating

The file tree is the index for everything except this page and
[Tasks](tasks/index.md), which the Board renders as cards rather than showing
in the tree.

Every page declares whether it is **prescriptive** (authored intent — a
decision or a requirement, superseded rather than edited once accepted) or
**descriptive** (the current picture, kept up to date as it changes).
